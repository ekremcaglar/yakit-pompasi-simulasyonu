# Yakıt Pompası Simülasyonu

Galip için eğitim ve test amaçlı etkileşimli yakıt pompası simülasyonu.

Birim fiyatlar **örnek değerlerdir**; güncel gerçek pompa fiyatı değildir.

Uygulama: `index.html` (tek dosya, tarayıcıda açılır).

GitHub Pages yayını için depoda Settings → Pages → Source: **GitHub Actions** bir kez açıldıktan sonra adres:

https://ekremcaglar.github.io/yakit-pompasi-simulasyonu/
